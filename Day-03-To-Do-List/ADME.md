# 📝 Day 3 – To-Do List

A simple **command-line To-Do List** built with Python as part of my **30 Days Python Project Challenge**.

## ✨ Features

* ➕ Add tasks
* 👀 View tasks
* 🗑️ Delete tasks
* ❌ Exit the program

## 🛠️ Concepts Used

* Lists
* `while` & `for` loops
* `if-elif-else`
* `input()`
* `append()` & `pop()`
* `enumerate()`
* F-strings

## ▶️ Run

```bash
python todo_list.py
```

Practice Python **lists, loops, conditions, and user input** by building a useful mini-project.
