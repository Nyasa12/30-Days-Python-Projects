# Day 2 – Number Guessing Game

This is my **Day 2 project** of the **30 Days Python Project Challenge**.

## 📌 About

A simple command-line number guessing game where the computer randomly selects a number between 1 and 100, and the player keeps guessing until they find it.

## ✨ Features

- Random number generation
- User guessing system
- Higher/Lower hints
- Repeated guesses until correct
- Winning message

## 🛠️ Concepts Used

- `random` module
- Variables
- `input()`
- `int()`
- `if-elif-else`
- `while` loop
- Comparison operators

## ▶️ How to Run

```bash
python 02_python_num_guess.py
