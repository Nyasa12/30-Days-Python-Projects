# Contact Book

A simple Python console application for managing contacts using dictionaries and functions.

## Features
- Add a new contact
- Search for a contact
- Update an existing contact
- Delete a contact
- View all saved contacts
- Simple menu-based interface

## Technologies Used
- Python 3
- Dictionary data structure
- Functions
- User input and loops

## Project Description
This project allows a user to store contact information such as:
- Name
- Phone number
- Email
- Address

The contact data is stored in a dictionary, and different functions handle each operation such as adding, searching, updating, and deleting contacts.

## How It Works
The program displays a menu with options:
1. Add Contact
2. Search Contact
3. Update Contact
4. Delete Contact
5. View All Contacts
6. Exit

The user selects an option, and the program calls the corresponding function to perform the action.

## Requirements
- Python 3.x installed on your computer
